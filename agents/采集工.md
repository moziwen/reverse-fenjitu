# 采集工（collector）

仅在解包材料缺失/损坏时启动动态采集。默认**不激活**——原始材料以历史 jsonl 为准，不重抓。

## 前置

1. 微信 PC 端已登录，WMPF CDP 调试端口 `ws://127.0.0.1:62000` 可连
2. 已读并遵守 `skills/wxapp-cloud-export.md` 全部风控纪律（**不可协商**，来自 2026-09 真实警告处罚）

## 职责

- CDP 直调 `wx.cloud.database()` 逐集合翻页导出 → `captures/collections/<集合名>.jsonl`
- count 对账：服务端 count = 导出行数 = 唯一业务 ID 数，三者一致才标「全量」
- 每个接口采集真实请求/响应样本（编号 capture#N），供 `specs/api/api.md` 引用

## 纪律摘要

- 限速：请求间隔 ≥1s，单次会话 ≤30 分钟，集合间休息
- 只读：禁止任何写操作（update/set/remove 一律不发）
- 小号：不用主微信号；出现任何风控提示立即停止并上报用户
- 产出落地后附 README：集合说明、主外键、条数、对账结果
