# CDN 可达性探测报告（阶段 2 前置验证）

> 执行时间：2026-09-29。方法：HTTP HEAD 请求（curl），本机直连。
> 结论：**24/24 全部 200 可达**，含 3 类资源全链路。

## 探测结果

| 类别 | 样本数 | 结果 |
|---|---|---|
| 图标/装饰（icon/daka/listen/gif） | 16 | 全部 200 |
| 音频（letter/页音频三态 .mp3/.mp3中/.mp3慢） | 4 | 全部 200 |
| 封面（Cover 正常版/Big 版） | 2 | 全部 200 |
| 分享图/二维码（qianyufang.top + TCB 云存储双域名） | 2 | 全部 200 |

## 关键发现

1. **音频三态规律实测命中**：`AA/farm-animal/dog.mp3`（英）/ `dog0.mp3`（中）/ `dog1.mp3`（慢速）全部存在——spec 里「页音频=页图文件名换扩展名」的规律由 HTTP 层面直接证实。
2. **封面双字段规律命中**：`AA/Cover/farm-animal.jpg` 与 `AA/Cover/Big/farm-animal.jpg` 均可达，与 jsonl 里 `cover`/`cover_big` 字段一致。
3. **TCB 云存储域名仍存活**：`636c-cloud1-...tcb.qcloud.la` 可达（shareImg.png 200）。

## 对 spec 的影响

6 页 spec 中标「待真机验证」的 **29 处 CDN 资源**：其中 URL 可静态枚举的部分已由本报告覆盖（HTTP 200 即可达，与真机无关）；仅在真机运行时动态拼接的 URL 仍保留标记，但模式（目录+命名规律）已被本报告证实。

**建议**：spec 中「待真机验证」可降级为「HTTP 已验证，真机播放待前端联调时抽听」。剩余 21 页蒸馏时可引用本报告，同类标记直接降级。
